# React Component Development

## Objective

Create simple, reusable and maintainable React components.

## Technology restrictions

- Use React with JavaScript.
- Never use TypeScript.
- Use functional components.
- Use JSX.

## Component conventions

1. Use PascalCase for component filenames.
2. Use descriptive component names.
3. Keep components focused on one responsibility.
4. Use props to pass data between components.
5. Avoid unnecessary state.
6. Use React hooks when appropriate.
7. Separate styles into CSS Modules files.
8. Use semantic HTML elements.
9. Consider accessibility.
10. Avoid unnecessary dependencies.

## Implementation workflow

When creating a component:

1. Understand its responsibility.
2. Identify its required props.
3. Consider whether it needs local state.
4. Propose the component structure.
5. Implement the component.
6. Explain the important decisions.
7. Identify whether the component requires knowledge from other project skills.
8. Use complementary skills when necessary, such as react-routing for navigation.

## Quality checklist

Before finishing:

- Check that the component has a clear responsibility.
- Check that props are correctly used.
- Check that no unnecessary state exists.
- Check accessibility.
- Check that the component follows the project conventions.
