
# DevStore

## Project Overview

DevStore is a frontend-only ecommerce application.

The objective is to build a small ecommerce application for learning modern frontend development and agentic coding practices.

## Technology Stack

- React
- JavaScript (no TypeScript)
- Vite
- React Router DOM
- CSS Modules
- JSON mock data

## Architecture Rules

- Use functional React components.
- Use React hooks when appropriate.
- Separate components, pages and data.
- Use React Router DOM for navigation.
- Keep the application frontend-only.
- Do not implement a backend.
- Simulate authentication on the frontend.

## Coding Standards

- Use PascalCase for React components.
- Use camelCase for variables and functions.
- Prefer small and reusable components.
- Avoid unnecessary dependencies.
- Avoid unnecessary abstractions.
- Write readable and maintainable code.
- Use semantic HTML.
- Consider accessibility.

## Agent Working Rules

- Explain the proposed approach before complex changes.
- Work incrementally.
- Do not modify unrelated files.
- Ask before introducing new dependencies.
- Do not implement features outside the requested scope.
- Explain important technical decisions.
- Verify changes before considering a task complete.

## Learning Guidelines

The developer is learning agentic coding.

- Prefer simple solutions over complex abstractions.
- Explain why a solution is appropriate.
- Identify relevant React concepts.
- Do not hide important implementation details.
- Encourage understanding rather than blindly generating code.
